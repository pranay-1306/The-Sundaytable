# Sunday Table app files

This folder contains the browser app: the page, styles, and client-side interactions.

The app supports recipes, voice memos with manual transcripts, family stories, photos, cookbook themes, sample-content visibility, printing, and optional family sync. Audio is not sent for automatic transcription.

For setup and testing, see the [project guide](../README.md). Keep the server data directory persistent when hosting; never commit the family passphrase or family collection data.
