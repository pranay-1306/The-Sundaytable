Privacy & storage

When connected, recipes, stories, voice recordings, and photos are sent to the family server and synced to signed-in browsers.

  • Anyone with the family passphrase can view and edit the shared collection.
  • The server keeps up to 12 earlier collection snapshots. Removed text can remain in those snapshots until they age out.
  • Uploaded media is stored on the server. There is no cloud transcription or external speech service connected.
  • This app has no individual accounts or per-person access revocation yet. Use a trusted group and a strong passphrase.

The family host is responsible for keeping persistent storage enabled. If the host's data disk is removed, the shared collection can be lost.
